# 基于GPT-SoVITS的少样本中文语音克隆系统
人工智能选修课期末项目

## 项目简介
本项目基于GPT-SoVITS v2端到端语音克隆框架，实现了仅需5秒参考音频的高质量中文语音克隆。系统支持在普通Windows CPU环境下离线运行，提供直观的Web操作界面。

## 运行步骤
1. 安装依赖：`pip install -r requirements.txt`
2. 启动WebUI：`python webui.py`
3. 打开浏览器访问：http://127.0.0.1:7860

## 预训练模型
预训练模型可从官方GitHub下载：https://github.com/RVC-Boss/GPT-SoVITS
